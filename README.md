# Diagram เชื่อมโยงปัจจัยเสี่ยง

เว็บแอปไฟล์เดียว (`index.html`) สำหรับสร้าง Diagram เชื่อมโยงปัจจัยเสี่ยง พร้อมใส่สีตามผลการบริหารความเสี่ยง และ export เป็น PNG / PDF

## วิธีใช้
1. เปิด `index.html` ด้วย Chrome หรือ Edge (ต้องต่ออินเทอร์เน็ตเพื่อโหลดไลบรารีและฟอนต์)
2. กด **อัปโหลดไฟล์** แล้วเลือก
   - PDF ผลการบริหารความเสี่ยงระดับส่วนงาน/หน่วยงาน (จากระบบสารสนเทศสนับสนุนการบริหารความเสี่ยง)
   - Excel ผลปัจจัยเสี่ยงองค์กร (ชีตละ 1 ปัจจัยเสี่ยง + สาเหตุ R1, R2 …)
   - (ถ้ามี) ไฟล์การเชื่อมโยง `.json` ที่บันทึกไว้
3. เลือกปัจจัยเสี่ยงองค์กร แล้วกด **เชื่อมโยงปัจจัยเสี่ยง** ที่แต่ละสาเหตุ เพื่อเลือกปัจจัยเสี่ยงระดับสายงาน (เช่น UR11)
4. Export PNG / PDF ได้จากปุ่มด้านบน

ไฟล์ทั้งหมดอ่านในเบราว์เซอร์เท่านั้น ไม่มีการส่งข้อมูลออก

## โครงสร้าง Diagram
ปัจจัยเสี่ยงองค์กร → สาเหตุความเสี่ยง (R) → ระดับสายงาน (UR01) → ระดับส่วนงาน (UR0101) → ระดับหน่วยงาน (UR010101)

ระดับความเสี่ยง (คะแนน L×I): ต่ำมาก 1–2 · ต่ำ 3–4 · ปานกลาง 5–9 · สูง 10–16 · สูงมาก 17–25 (ปรับได้ในแอป)
